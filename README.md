# invest-folio

**Data-Driven Investment Intelligence on NIFTY-50 Market Data**

An offline, explainable decision-support platform that transforms 20+ years of
NIFTY-50 historical data into actionable investment intelligence — stock
prediction, portfolio construction, and risk assessment — with transparent,
quantitatively-justified recommendations.

Built for the Cult Council Open Project. Uses **only** the provided NIFTY-50
dataset: no live data, financial APIs, news feeds, or sentiment data.

---

## Features

- **Stock Predictor** — XGBoost direction classifier + return regressor, with leak-free chronological validation and SHAP explanations for every prediction.
- **Portfolio Construction** — efficient-frontier optimization (Monte Carlo + exact convex) mapped to three investor profiles (Conservative / Balanced / Aggressive), each with quantitative justification.
- **Risk Assessment** — volatility, Sharpe, Sortino, max drawdown, beta, Calmar, CAGR for any stock or portfolio.
- **Explainability** — SHAP global and per-prediction decomposition, plus plain-English rationales.
- **Interactive Dashboard** — a 4-tab Streamlit app tying everything together.

## Setup

### 1. Clone and create a virtual environment
```bash
git clone https://github.com/1Priyanshu18/invest-folio
cd invest-folio
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Download the dataset
Download the [NIFTY-50 Stock Market Data](https://www.kaggle.com/datasets/rohanrao/nifty50-stock-market-data)
from Kaggle and place **all** CSVs — the 50 stock files plus `stock_metadata.csv`
and `NIFTY50_all.csv` — into `data/raw/`.

### 4. Verify setup
```bash
cd src
python check_setup.py
```
Expect: "Phase 0 setup looks good" with 50 stock CSVs detected.

## Running the Project

All module scripts are run from inside `src/`. The dashboard is run from the repo root.

### Train the prediction models
Trains the classifier + regressor for the full investable universe (~45 stocks)
and saves model bundles to `outputs/models/`:
```bash
cd src
python predictor.py train
```
*(~5 minutes. Produces `outputs/predictor_results.csv`.)*

### Generate report figures
```bash
cd src
python make_figures.py
```
Saves Figures 01–07 to `outputs/figures/`. SHAP figures (08–10) are produced
from `notebooks/03_explain.ipynb`.

### Launch the dashboard
From the **repo root**:
```bash
streamlit run app/dashboard.py
```
Opens at `http://localhost:8501` with four tabs: Stock Explorer, Prediction,
Portfolio Builder, and Market Overview.

### Run individual modules (self-tests)
Each module has a self-test demonstrating its functionality:
```bash
cd src
python data_loader.py     # loading + alignment
python risk.py            # risk metrics (cross-checked vs EDA)
python portfolio.py      # efficient frontier + profiles
python predictor.py      # single-stock prediction + walk-forward CV
python explain.py        # SHAP global + local explanation
```

## Reproducing Results

All results reproduce deterministically from the committed code:

- A fixed random seed (`RANDOM_SEED = 42` in `src/config.py`) governs all
  stochastic steps (Monte Carlo, model training, sampling).
- Financial assumptions (risk-free rate 6.5%, 252 trading days) are centralized
  in `src/config.py`.

**Full reproduction from scratch:**
```bash
pip install -r requirements.txt
# place dataset CSVs in data/raw/
cd src
python check_setup.py        # verify data
python predictor.py train    # train + save models, write results CSV
python make_figures.py       # regenerate figures
cd ..
streamlit run app/dashboard.py   # launch the app
```

Raw data and generated artifacts (models, figures) are gitignored; they are
regenerated by the commands above.

## Methodology Highlights

- **Leak-free validation:** chronological train/test split, `TimeSeriesSplit`
  cross-validation, scaler fit on training data only, naive baselines.
- **Split-adjusted returns:** corporate actions detected via `Prev Close` and
  neutralized (the dataset provides no adjusted close).
- **Honest reporting:** directional edges are small and stock-specific
  (~50–54%), consistent with market efficiency; the predictor is positioned as
  one decision input, not a standalone trading signal.

See `report.md` for the full methodology and findings.
